# ROOFORA — WEBSITE VISION

## 01. PROJECT PURPOSE

We are building a premium modern roofing-company website template.

This is NOT just a pretty landing page.

The website must work as a real business website whose purpose is to:

- Build trust
- Show quality of work
- Explain services
- Reduce homeowner hesitation
- Make the company feel professional and established
- Generate calls and quote requests
- Clearly communicate the company's service area
- Make the customer understand what happens after contacting the company

The final template should be good enough that we can customize it for real roofing contractors and use it as a professional client demo.

---

# 02. PRIMARY VISUAL REFERENCE

A reference image will be provided separately.

STRICTLY USE THE PROVIDED REFERENCE IMAGE AS THE PRIMARY DESIGN DIRECTION.

The reference image defines the overall:

- Layout style
- Visual hierarchy
- Spacing
- Typography direction
- Card treatment
- Border radius
- Image usage
- Color direction
- Section composition
- Navigation style
- CTA treatment
- Trust elements
- Overall visual quality

Do NOT create a generic roofing template.

Do NOT fall back to old 2018-style business websites.

Do NOT make every section look like a collection of identical cards.

The final website should feel:

MODERN
PREMIUM
STRONG
SAFE
TRUSTWORTHY
PROFESSIONAL
CLEAN
CONVERSION-FOCUSED

Modern design is equally important as the themes of strength, safety and protection.

---

# 03. DESIGN PHILOSOPHY

The website should communicate:

"These people know what they're doing, they protect my home, they do quality work, and I can trust them."

The design should feel modern through:

- Strong typography
- Excellent spacing
- Editorial layouts
- High-quality imagery
- Subtle gradients
- Layered visual elements
- Refined cards
- Clean iconography
- Asymmetric compositions where appropriate
- Premium CTA design
- Subtle interactions
- Strong visual hierarchy
- Smooth transitions

Do NOT add animations just for the sake of animation.

Do NOT sacrifice usability for visual effects.

---

# 04. HOMEOWNER-FIRST THINKING

Always design from the perspective of a homeowner.

A homeowner visiting the website wants answers to:

1. What does this company do?
2. Do they serve my area?
3. Can I trust them?
4. Have they actually done good work?
5. What services do they provide?
6. What will happen after I contact them?
7. Is the estimate clear?
8. Do they offer financing?
9. What do previous customers say?
10. How can I contact them immediately?

Every section should answer one or more of these questions.

Possible elements:

- Years of experience
- Projects completed
- Google rating
- Licensed & insured
- Certifications
- Warranty
- Quality materials

- Communication

We should communicate:

"Clear Estimates. No Surprise Costs."

Do not invent financing offers.

Do not invent prices.

The design should communicate transparency.

# 17. RESPONSIVENESS

The website must be designed mobile-first.

Do not simply shrink the desktop layout.

Mobile must have:

- Easy navigation
- Large readable typography
- Comfortable touch targets
- Strong CTA visibility
- Proper image cropping
- No horizontal overflow
- Fast loading
- Clear content hierarchy

Desktop and mobile should both feel intentionally designed.

---

# 18. TECHNICAL QUALITY

Use clean, maintainable code.

Preferred stack:

- React
- Tailwind CSS
- JavaScript / TypeScript where appropriate
- Vite
- Git

Use reusable components.

Avoid unnecessarily complicated architecture.

Do not create a backend unless the feature actually requires one.

For forms, booking, analytics and similar functionality, use appropriate reliable services when possible.

---

# 19. AI DEVELOPMENT RULE

AI-generated code must NOT be blindly trusted.

Before implementing complicated functionality:

- Explain what it does
- Explain why it is needed
- Verify it works
- Test failure states
- Keep secrets out of frontend code
- Never expose API keys
- Never claim a feature works without testing it

The developer owns the code even when AI generates it.

---

# 21. REFERENCE IMAGE RULE

The provided reference image is the visual benchmark.

When implementing each section, compare the result against the reference.

If the implementation starts looking:

- Generic
- Old-fashioned
- Template-like
- Overly corporate
- Visually flat
- Too card-heavy
- Like a 2018 website

STOP and reconsider the implementation.

Do not invent a completely different design direction.

If something is unclear from the reference, ASK before making a major design decision.

---

# 22. DEVELOPMENT DISCIPLINE

Do not build features that were not requested.

Do not redesign the entire site after every instruction.

Complete the current step first.

After completing a step:

1. Verify the implementation.
2. Run the project.
3. Check desktop.
4. Check mobile.
5. Fix obvious issues.
6. Report what was completed.
7. Wait for the next instruction.

---

# 23. IMPORTANT

This is a professional website template intended to eventually be shown to real businesses.

Do not optimize for:

"Looks cool in a screenshot."

Optimize for:

"Looks premium, feels trustworthy, answers homeowner questions, and makes the visitor want to contact the company."

The final result should feel like a modern premium roofing brand in 2026.

NOT a generic roofing template.

NOT a SaaS template.

NOT a 2018 corporate website.

NOT an over-animated design experiment.

Modern + Strong + Safe + Trustworthy + Conversion-focused.
